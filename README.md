# appkitc
<img src="docs/img/badges.svg">

Writes the `main` files of a webtyp appkit app (`web/server`, `web/browser`, `migrate`, `config/services`) and is pinned by each app in its own `go.mod`.

## Why This Exists

A webtyp app declares itself once, in `config/` ([appkit](https://github.com/webtyp/appkit)); its `main` files are generated from that declaration. You meet `appkitc` the first time `webtyp dev` starts an app, and again every time you upgrade `appkit` or `layout`.

| Without this | With this |
|---|---|
| The templates travel inside the installed `webtyp` binary. An old binary rewrites your `main` files with a template that no longer matches the libraries in `go.mod`, and the build fails with `undefined: layoutapp.Browser`. | The app pins `appkitc` in its `go.mod` like any other library. `go get -u` upgrades the libraries and the templates together, and `appkitc` does not publish until its templates compile against them. |

How the pieces fit: [docs/diagrams/GENERATED_MAINS.md](docs/diagrams/GENERATED_MAINS.md). Where this repo sits in the framework: [docs/diagrams/PLACEMENT.md](docs/diagrams/PLACEMENT.md).

## Before You Start

- Go 1.24 or newer (the `tool` directive of `go.mod`); the workspace uses the version in [go.mod](go.mod).
- An app that declares `var App = appkit.App{…}` in `config/`, with `config/services` and `config/screens` ([ARCHITECTURE](https://github.com/webtyp/appkit/blob/main/docs/ARCHITECTURE.md)).
- Nothing to install: `webtyp dev` adds the `tool` line to the app's `go.mod` the first time.

## Step-by-Step Guide

### Step 1: Pin the generator in the app

**Goal:** make the app choose the generator version.

```sh
go get -tool webtyp.com/appkitc/cmd/appkitc@latest
```

**Expected result:** `go.mod` gains `tool webtyp.com/appkitc/cmd/appkitc` and a `require webtyp.com/appkitc` line.

### Step 2: Write the main files

**Goal:** generate the files from `config/app.go`.

```sh
go tool appkitc -port=8080 -public-dir=web/public
```

**Expected result:** the command prints the path of `web/server/main.go`; `web/browser/main.go`, `migrate/main.go` and `config/services/{migrations,removed}.go` are written next to it. A file without the `Code generated by webtyp.com/appkitc` header is yours and is never touched ([generate.go](generate.go)).

### Step 3: Upgrade

**Goal:** take newer templates together with the libraries they call.

```sh
go get webtyp.com/appkitc@latest
```

**Expected result:** `appkit`, `layout`, `devtools` and `migrate` rise to at least the versions `appkitc` was tested with; the next `webtyp dev` rewrites the generated files.
