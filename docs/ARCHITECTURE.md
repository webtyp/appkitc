# appkitc — architecture

## 1. Overview in One Minute

`appkitc` turns the declaration of an app (`config/app.go`) into the files that start it: the server, the browser and the migration binary. It is a development tool: no app imports it and no production binary contains it. Each app pins the version it wants in its own `go.mod` with a `tool` line, and `webtyp dev` only asks Go to run that version (`go tool appkitc`). The templates therefore always come from the same release train as the libraries they call.

## 2. Repository Pieces & On-Disk Layout

| File | Single responsibility |
|---|---|
| [cmd/appkitc/main.go](../cmd/appkitc/main.go) | Reads the flags `server` defines, calls `GenerateMain` in the current folder, prints the path of the server main. |
| [generate.go](../generate.go) | `GenerateMain`: chooses what to write for the kind of project, writes only files that carry the generated header, completes `go.mod` when output changed. |
| [templates.go](../templates.go) | The templates, one constant each; the only place that knows what a generated file contains. |
| [services.go](../services.go) | Refuses an app whose `config/` is not split by side and moves the old `removed.go`. |
| [migrations.go](../migrations.go) | Builds `config/services/migrations.go` from `App.Modules`. |
| [register_args.go](../register_args.go) | The `Register(...)` call of apps that still use `config/routes.go`. |
| [tests/fixtureapp/](../tests/fixtureapp) | The smallest compilable app; its generated files are committed and compiled by the tests. |

## 3. Step-by-Step Flows

- **Generate:** [docs/diagrams/GENERATED_MAINS.md](diagrams/GENERATED_MAINS.md) — `webtyp dev` reads the app's `go.mod`, runs the pinned `appkitc`, which writes the files; if any changed it runs `go mod tidy` so imports the new templates add are listed.
- **Publish:** the fixture test regenerates the fixture, compares it with the committed copy and compiles it (native and `GOOS=js GOARCH=wasm`) against the libraries in `go.mod`. A template that does not compile fails here, never in an app.

## 4. Security Boundaries & Contracts

- `appkitc` imports `webtyp.com/server` (project detection, `MainConfig`, flag names) and the libraries its templates call; neither `server` nor `appkit` may import `appkitc`, or the tool would enter production.
- A test fails if any main of the fixture depends on `webtyp.com/appkitc`.
- A file without the `Code generated by webtyp.com/` header belongs to the developer and is never written.
- No `go.mod`/`go.sum` line is written by hand: only `go get` and `go mod tidy`.
